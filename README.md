## The word

**beepboop**

The single word my grandma would text about AI. She has no idea how the robot works, so she just imitates the noise it makes — warm, a little baffled, and funny with no caption needed.

## What it does

`main.ts` validates the entry (exactly one word, 1–30 characters, no whitespace) and writes it to `/output/entry.txt`.

## How to run

Requires Node 22 or later. No dependencies, no network.

```sh
node main.ts
cat /output/entry.txt
```
